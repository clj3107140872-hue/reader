# 回归测试清单（Reader）

每次改动或发版前过一遍本清单。每一项都是**曾经真实出现过的问题**；改到相关代码时重点验这一条，避免改几次后又复现。最新的在上，新问题修完后追加到对应分组。

## 目录与章节（最近改动，优先回归）

- [ ] 点目录跳到很后面的章节**不卡死**（曾是 0.5–1.9 秒假死）；落点就是所选章节，不在别处。
- [ ] 打开目录时自动滚到**当前阅读章节并居中**（2026-11-05）。
- [ ] 合并/重新切分后，目录里**没有同标题的重复章节**；截断副本和「(内容为空)」占位被删除，内容不同的同名章节（前言、番外）保留。
- [ ] 标题以 `！` `？` `…` 结尾的真实章节（`第506章 收网！`）能切开；正文句子（`第一章讲的什么？`）不会被当成标题。
- [ ] 没有章节标题的 txt 按单章导入并给出提示；手动标记章节后目录随之变化。
- [ ] 目录搜索过滤正常；重复章节的「重复?」徽标。

## 阅读与进度

- [ ] 正文只渲染「上一章/当前章/下一章」三章（2026-11-05）：滚到章尾自动滑一章、滚到章首自动补前一章，**滑动瞬间正文不跳**；目录/进度条/搜索跳到远处章节也能落到正确位置。
- [ ] 关闭再打开书，回到上次阅读位置（合并、重切、换编码之后也要按章节标题映射回来）。
- [ ] 书签可添加/跳转/删除，跳转准确。
- [ ] 目录/搜索/书签/设置侧边栏：**点击正文区域（或进度条）即关闭**，点侧边栏内部不关，工具栏按钮可直接切换；Esc 也能关（2026-11-05）。
- [ ] 翻页模式：滚轮/方向键/空格翻页，章末自动进下一章；切回卷轴模式落点不跑偏。
- [ ] 页码、剩余时间显示合理；字号/行距/段距/页宽调整后位置不丢。
- [ ] 全屏 F11、方向键、Ctrl +/- 快捷键不冲突（没有默认菜单抢键）。
- [ ] 深浅主题：夜间/日间切换作用于**整个外壳**（书架、设置、弹窗），阅读背景独立；深色背景在日间不会被选中。
- [ ] 代码伪装模式：整行吸附、滚轮一格一行、VS Code 2026 Dark 配色正常。

## 导入、合并与数据

- [ ] GBK/UTF-8/带 BOM 的 txt 导入不乱码；双重编码的旧文本不会被误「修复」。
- [ ] 清洗：广告行/重复段落被删除，计数正确；关闭清洗时正文不丢。
- [ ] 较大的文件导入先确认；书架支持拖放导入。
- [ ] Epub（无 DRM）可导入阅读，封面/作者/目录正常；加密正文被拒绝；TXT 导入不受影响。
- [ ] 同一本书重复导入时提示合并；合并后卷序、章节顺序正确，书签/进度按标题映射保留。
- [ ] 缺章的旧书能从保存的原文重建缺章；换编码后手动章节标记保留。
- [ ] 重新清洗/重新切分后进度保留、生成备份；批量重洗/删除不影响其他书。
- [ ] 书架删除、批量删除、排序、悬停信息正常；拖拽导入暂停提示正常。

## 窗口与伪装

- [ ] 拖动窗口边缘缩放**不卡死**（重复坐标风暴）；透明窗口最小 120×80。
- [ ] 代码/透明摸鱼模式下按住边缘连续缩放**不卡顿**：拖动时正文宽度先固定，松开后一次重排（长书 900 章也不应逐帧重排）。
- [ ] 摸鱼模式：记事本/透明悬浮/代码注释切换后阅读进度保留；老板键隐藏与恢复；透明窗口文字随桌面亮度变化。
- [ ] 窗口大小、位置、最大化状态重启后恢复。

## 启动与数据安全

- [ ] 绿色版双击启动约 1 秒；portable exe 因自解压约 6–7 秒属正常，不是回归。
- [ ] 只保留中文/英文语言包，界面不出现英文。
- [ ] 单实例：重复启动只聚焦已有窗口，不开第二个。
- [ ] `library.json` 损坏时能从 `.bak` 自动恢复；备份目录可恢复。
- [ ] 启动日志写入 `data/logs/app.log`；复制整个绿色目录可带走全部书籍、设置与进度。
- [ ] 自动化验收只在离屏 + 临时数据目录跑（`READER_ACCEPTANCE=1`），不弹窗、不动真实 `data/`。

## 发版

- [ ] `npm test`（全绿）、`npm run typecheck`、`npm run build`。
- [ ] 打包版离屏冒烟：能启动、`app start` 日志正常、窗口不可见（注意本机 shell 的 `ELECTRON_RUN_AS_NODE=1` 要先去掉）。
- [ ] Release 附件能匿名下载（`curl -sIL` 返回 200），校验值与说明一致。
