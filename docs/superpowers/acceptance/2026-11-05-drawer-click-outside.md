# 侧边栏点击正文自动关闭（2026-11-05）

## 现象

目录、搜索、书签、设置四个侧边栏打开后必须点右上角 × 才能关闭，点正文没有任何反应；用户已习惯「点空白处关闭弹层」。

## 修复

`Reader.tsx`：某个侧边栏打开时挂一个 `pointerdown` 监听，事件目标不在侧边栏、也不在工具栏内就 `setDrawer(null)`。

- 侧边栏内部点击不关闭（滚动目录、调设置、输入搜索词都不受影响）；
- 工具栏排除在外：目录打开时点「搜索」直接切换到搜索面板，而不是先关再开；
- 进度条、正文、页边空白都算「外部」，点击即关闭；Esc 行为不变。

侧边栏是 `position: fixed` 的顶层元素，点击它本身不会冒泡到阅读区，所以不需要额外的遮罩层。

## 验证（离屏 `READER_ACCEPTANCE=1`，临时数据副本，不触碰真实 `data/`）

用 CDP 真实鼠标事件：

| 步骤 | 结果 |
| --- | --- |
| 打开目录 → 点正文 | 关闭 |
| 目录打开时点工具栏「搜索」 | 直接切换为搜索面板 |
| 搜索打开 → 点正文 | 关闭 |
| 打开设置 → 点侧边栏内部（标题栏） | 保持打开 |
| 设置打开 → 点正文 | 关闭 |
| 打开目录 → 按 Esc | 关闭 |
