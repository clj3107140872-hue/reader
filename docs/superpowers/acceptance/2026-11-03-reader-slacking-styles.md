# 摸鱼模式多风格验收记录（2026-11-03）

> 本记录覆盖 `2026-11-03-reader-slacking-mode.md` 之后的第二版：`disguise` 由布尔值改为枚举，新增「透明悬浮」「代码注释」两种风格。不透明度、置顶、老板键的验收结论沿用前一份，并在本次回归中重跑。

## 改动

- 设置 `slacking.disguise` 改为枚举：`none` / `notepad` / `transparent` / `code`，默认 `none`。
  - 兼容旧配置：`true` 迁移为 `notepad`，`false` / 非法值迁移为 `none`；`tests/settings.test.ts` 覆盖。
- 设置面板「摸鱼模式」改为四选一按钮（关闭 / 记事本 / 透明悬浮 / 代码注释），选中后显示对应说明。
- 日间/夜间主题与阅读背景分离：
  - `themeMode`（日间 / 夜间 / 跟随系统）现在控制整个应用外壳：书架、设置抽屉、弹窗、提示条。解析结果写到 `<html data-app-theme="night|day">`，夜间样式统一覆盖背景、卡片、输入框、按钮、边框、toast 等。
  - 阅读页内部仍由 `theme`（浅色 / 深色 / 护眼绿 / 羊皮纸）控制，两套变量互不影响；伪装窗口（`body[data-slacking]`）不套用外壳配色。
  - 夜间模式下点选背景色只记住选择、不改变当前深色阅读页；切回日间或跟随系统（且系统为浅色）后才按所选背景渲染。设置面板在夜间模式显示对应说明。
  - 设置里的阅读背景只展示「浅色 / 护眼绿 / 羊皮纸」：夜间模式固定深色，日间模式下深色会被规范化回浅色，那个「深色」色板永远无法被选中，因此不再展示；夜间模式下高亮的是被记住、切回日间后生效的底色，点选后高亮立即跟随。
- 阅读页工具栏「摸鱼」按钮不再直接进入记事本，改为展开同款样式菜单（记事本 / 透明悬浮 / 代码注释），点外部或按 `Esc` 关闭；设置面板入口保留。
- 透明 / 代码窗口去掉右上角的 `×`（`Esc` 就是退出方式，按钮反而突兀）；每次进入任意伪装（含换窗口后重新挂载）顶部弹出 4 秒提示「摸鱼模式：按 Esc 退出」。
- 窗口形态按「风格 + 是否有书」决定（`disguiseWindowKind`）：
  - 书架页始终是带边框的普通窗口；只有打开书籍时才应用透明 / 代码形态。
  - 透明、代码两种风格需要改 `frame` / `transparent` / `resizable` 等构造参数，切换时新建窗口、旧窗口在就绪后销毁；切换前通过 `app:flush-request` / `app:flush-done` 等待阅读进度落盘，5 秒兜底。
  - 新窗口以 `?bookId=&style=` 启动，首帧即按目标风格渲染；阅读位置随进度恢复。
- 透明悬浮：
  - 无边框、透明背景、不可调整大小、无阴影；正文与背景全透明，只留文字。
  - 主进程每 2 秒（移动/缩放后 250ms 防抖）用 `desktopCapturer` 抓窗口身后画面，裁剪窗口区域后取中位亮度，经 `slacking:backdrop` 通知渲染层；深色背景用浅色文字，浅色背景用深色文字，颜色切换有 200ms 过渡。
  - 验收模式跳过真实采样；`debug:backdrop` 用于驱动同一通道。
- 代码注释：
  - 无边框、32 位深不透明窗口，配色对齐 VS Code 1.138 内置 **2026 Dark** 主题（`editor.background` `#121314`）；不再有顶部标签栏、底部蓝色状态栏和任何窗口内框，代码与正文直接铺满窗口。
  - 代码色板与主题一致：行号 `#858889`，正文 `#c9d1d9`，关键字 `#ff7b72`，字符串 `#a5d6ff`，函数名 `#d2a8ff`，数字 `#79c0ff`，注释（含正文）`#8b949e`。
  - 顶部保留 14px 高的透明拖动条（`.code-drag-strip`，`-webkit-app-region: drag`），看不见但可以拖动无边框窗口；四边/四角的缩放拖拽条仍然有效。
  - 伪代码为约 160 行的完整文件（导入、编码探测、十个处理函数、章节缓存与导出），按窗口高度在正文上下各取一段；行号与中间注释段首尾相接，读起来是一个连续文件。
  - 正文按「行数」而不是像素宽度控制：默认 4 行，可调 2–12 行，每行固定 19px（VS Code 默认 Consolas 14px / 行高 19px，`// ` 前缀，悬挂缩进）。窗口变宽变窄只改变每行字数，行数不变。行号栏 72px、行号右对齐在距左 41px 处，和 VS Code 截图一致。
  - 正文带上下两条隐形拖拽带（`.code-band-handle`），上下拖动按整行增减行数；窗口太矮时自动减少行数，并始终在正文上方、下方各保留至少 1 行代码。
  - 行数记忆在 `localStorage` 的 `reader.codeCommentLines`。
  - 只能按整行滚动：鼠标滚轮一格固定推进 1 行（100px 记为一格；触控板的小增量先累积，满一格才走一行，事件一律接管，不会触发浏览器原生 3 行滚动），滚动位置在每次滚动后吸附到 19px 的整数倍；方向键「左」上一屏、「右」下一屏（整屏 = 当前行数 × 19px），`PageUp` / `PageDown` / `Space` 同义；滚动条隐藏，鼠标停在代码上滚轮依旧滚动正文。
- 窗口尺寸：
  - 无边框窗口在页面四边/四角提供 6–10px 的拖拽条，通过 `window:resize-start/move/end` 在渲染层捕获指针、主进程用 `setBounds` 调整窗口；透明窗口保持 `resizable: false`（避免破坏透明合成），完全依赖这套自定义拖拽。
  - 自定义缩放的健壮性：渲染层对指针位置去重，并把移动合并为每个动画帧最多一次 IPC；主进程丢弃与上次完全相同的 bounds，尺寸上限钳制到虚拟桌面大小，`lostpointercapture` / 指针取消时自动结束缩放会话。避免窗口在指针下改变尺寸时反复回送同一位置的 move 事件、又触发下一次 `setBounds` 的自我反馈循环（拖动窗口大小导致卡死）。
  - 最小尺寸：透明 `120×80`，代码 `300×300`（普通窗口仍为 `800×600`）。300px 高在 19px 行高下能放下 12 行正文，并在上下各留 1 行代码。
  - 透明模式正文不再限制 `max-width`，窗口多大文字框就多大，缩小时同步换行。
- 退出：`Esc` 优先关闭设置抽屉，其次退出伪装（窗口换回普通形态），最后才返回书架；伪装下 Ctrl/Cmd 组合键不触发阅读快捷键。
- 阅读页标题：记事本/透明为 `工作文档.txt - 记事本`，代码为 `codenovel.js - Visual Studio Code`。
- 调试接口新增 `debugSetBackdrop`、`setViewState`、`onFlushRequest` / `notifyFlushed`、`onBackdropTone`；`debugWindowState` 增加 `disguise`、`windowKind`、`resizable`。

## 已知说明

- 透明窗口的原生 `resizable` 仍为 `false`（Electron 对透明窗口的缩放支持不可靠）；缩放完全由页面四边/四角的拖拽条驱动 `setBounds`，实测最小可到 `120×80`。
- 桌面采样只取窗口中心区域的中位亮度，背景一半黑一半白时按中位数取一侧，不保证每个字都对比充分。
- 代码注释模式的伪代码为固定生成的 160 行文案，仅作伪装背景，不随正文变化；上下两段按窗口高度取切片，行号连续；窗口过矮时自动减少正文行数，保证上下各至少 1 行代码。
- 正文行数只存在渲染层 `localStorage`（随 `userData` 迁移），不写 `settings.json`；窗口高度不足以容纳所选行数时会临时少显示几行，放大窗口后恢复所选行数。
- 日间/夜间只作用于应用外壳；阅读页背景仍按「浅色 / 深色 / 护眼绿 / 羊皮纸」单独选择，夜间模式下的选择会保存但不立即生效。
- 进入伪装的提示只是 4 秒的轻提示，不拦截操作；透明模式下它同样是一个深色小气泡。
- 书架页不应用透明/代码形态，避免「空书架透明悬浮」这种更反常的画面。
- 老板键注册失败（被其他程序占用）只写日志，界面暂不提示。
