# 书架批量操作与卡片信息 — 设计文档（2026-11-02）

## 背景

Plan 3 让书架具备了合并、重洗、重切、删除，但都是单本操作。实际使用暴露了三个缺口：

1. 卡片书名固定行数截断，书名相似（尤其是分卷文件）时难以分辨，需要看到完整书名与源文件名。
2. 合并只在导入时提示一次，「先不合并」之后没有入口，需要手动选择若干本书做合并判断。
3. 清理多本书只能逐本右键，需要选择模式与批量操作（删除、重新清洗、重新切章）。

同时借这次改动做少量内部整理（重复的分段/章节定位逻辑、错误文案），降低后续维护成本。

## 目标与非目标

**目标**

- 卡片悬停展示完整书名与全部元信息，不影响网格布局。
- 书架支持多选（任意勾选或全选），选中后可批量删除、重新清洗、重新切章。
- 选中若干本书后可「判断合并」：系统两两判断，逐对确认、方向自动执行。
- 消除 `splitParagraphs`、`resolveChapterIndex` 的三处重复；批量/删除失败提示统一为中文。

**非目标**

- 不改变 `library.json`、`meta.json`、书稿文件格式，不做数据迁移。
- 不做撤销/回收站；删除仍不可恢复（原始 TXT 不受影响）。
- 不做跨页面保留选择；离开书架页即清空。
- 不做自动合并（判断结果必须逐对人工确认）。
- 不做打包/发布相关改动。

## 交互设计

### 1. 卡片悬停信息

- 鼠标在卡片上停留约 350ms，或卡片获得键盘焦点时，在卡片旁弹出信息浮层；离开卡片/失焦即消失，滚动时隐藏。
- 浮层优先出现在卡片右侧，空间不足时翻到左侧；不遮挡所指向的卡片，尺寸固定，内容可换行。
- 内容（与「查看来源」弹窗复用同一份信息组件）：
  - 完整书名（不截断）
  - 章数、编码
  - 阅读进度百分比、最近阅读时间（未读显示「未阅读」）
  - 清洗统计：广告行数、重复段数、疑似重复章节数（为 0 时隐藏该项）
  - 全部源文件名（合并过的书会列出多个）
  - 导入时间
- 卡片本身尺寸、标题行数、网格布局不变；相似书名通过浮层里的完整书名与源文件名区分。
- 选择模式下不显示悬停浮层（避免与勾选操作冲突）。

### 2. 选择模式

- 工具栏新增「选择」按钮，进入选择模式：
  - 卡片左上角显示复选框；点击卡片 = 勾选/取消勾选，不打开书。
  - 右键与卡片「⋯」菜单均禁用；拖拽导入暂停（不显示遮罩）。
  - Esc 退出选择模式并清空选择。
- 工具栏在选择模式下变为：已选 N 本 / 全选（已全选时显示「取消全选」）/ 退出选择。
- 工具栏下方显示四个操作按钮：**判断合并、重新清洗、重新切章、删除**；未选中任何书或操作进行中时禁用。
- 排序切换不清空选择；离开书架页清空。

### 3. 判断合并（逐对确认，方向自动）

- 选中 ≥2 本后点「判断合并」（全选即对全部书判断）。
- 判断规则与导入提示一致（见 `sameBook.ts`）：
  - 两本书归一化书名相同，或章节重叠率 ≥ 5% → 视为候选。
  - 章节重叠率 = 以章节数较少的一本为分母，标题哈希相同且正文 simhash 汉明距离 ≤ 3 的章节占比。
- 主进程返回候选对，按重叠率降序排列；方向自动：
  - 章数多的书作为保留目标；章数相同则导入更早的作为目标。
  - 弹窗明确显示「将《B》合并到《A》」。
- 确认交互沿用导入时的队列式弹窗：一次显示一对「《A》 ⇄ 《B》· 章节重叠 87%」，按钮「合并 / 跳过」；处理完自动显示下一对。
- 合并复用现有 `MergeService` 逻辑（备份、跨章去重、进度与书签保留）。逐对执行：
  - 某对失败 → 提示错误，继续下一对。
  - 某本已被前一对合并掉 → 自动跳过该对并提示。
- 结束显示汇总：合并 N 对、跳过 M 对、失败 K 对。

### 4. 批量操作

- **批量删除**：确认弹窗显示「将删除 N 本书」并列出前几本书名，说明「原始 TXT 文件不会被删除；软件内的书籍数据和备份会删除」。确认后逐本删除，失败继续；完成后退出选择模式并刷新书架，汇总成功/失败数量。
- **批量重新清洗 / 重新切章**：确认弹窗说明规则（同单本：按当前内置清洗规则/重新识别章节标题）、会自动备份、阅读进度与书签保留；识别不到至少 3 个章节标题的书保持原样。逐本处理并显示「重新清洗 第 i/N 本」，失败继续；结束汇总并刷新书架，选择保留。
- 批量操作进行中 `actionBusy`，所有操作按钮与卡片交互禁用；任一操作完成前不能开始下一个批量操作。

## 技术设计

### 渲染层

- `Library.tsx` 新增状态：
  - `selectionMode: boolean`、`selected: Set<string>`、`hovered: { entry, rect } | null`
  - `batch: { kind, total, done } | null`（批量进度）
  - `mergeCandidates: MergeCandidate[]`（判断合并队列）
- 新组件：
  - `BookInfo`：纯展示的书目信息列表（供悬停浮层与「查看来源」弹窗复用）。
  - `HoverCard`：定位/避让/延迟显示逻辑；`position: fixed`，`pointer-events: none`。
  - 选择工具栏并入 `Library.tsx` 现有 toolbar，不单独建组件。
- `BookCard.tsx` 增加可选 props：`selectable`、`selected`、`onToggle`；选择模式下点击卡片触发 `onToggle`，否则 `onOpen`。
- 判断合并队列复用导入合并弹窗的结构（`mergeQueue` 的逐条弹出模式）。

### 主进程 / IPC

- 新增 IPC `library:find-merges`，对应 `window.api.findMerges(ids: string[])`；入参为已选书 id，返回：
  ```ts
  interface MergeCandidate {
    targetId: string
    targetTitle: string
    sourceId: string
    sourceTitle: string
    overlap: number // 0..1
  }
  interface FindMergesResult {
    candidates: MergeCandidate[]
    warnings: string[] // 例如「《书名》数据缺失，已跳过」
  }
  ```
  - 在 `LibraryService` 新增 `findMerges(ids)`：校验 id、先读取每本书的 meta（读不到的跳过并写入 warnings），再两两计算；条件为归一化书名相同或章节重叠 ≥ 0.05；按重叠率降序；方向按章数降序、同章数按导入时间升序。
  - 少于 2 本或没有候选时返回空 `candidates`，渲染层提示「没有发现可能是同一本书的候选」；`warnings` 非空时一并提示。
- 批量删除/重洗/重切**不新增批量 IPC**：渲染层按顺序逐本调用现有 `removeBook` / `recleanBook` / `resplitBook`，每本之间更新进度，失败收集后继续。原因：复用已验证的单本流程与库级互斥锁，失败粒度清晰。
- 合并逐对调用现有 `mergeBooks(targetId, sourceId)`；每对执行前用最新 `libraryList()` 校验两本仍存在。

### 内部整理

- 新增 `src/core/paragraphs.ts`：`splitParagraphs(text: string): string[]`，替换 `BookRepository.readBook`、`SearchService`、`Reader.tsx` 三处 `/\n{2,}/` 切分。
- 新增 `src/core/position.ts`：`resolveChapterIndex(chapters, chapterKey, fallback)`，替换 renderer 的 `position.ts` 与 `MergeService.remapChapterIndex` 两份实现。
- 删除/重洗/重切/合并失败的提示统一经 `errorText` 处理：已知消息原样显示，未知 Node 错误映射为固定中文文案（如「操作失败，请稍后重试」）。

## 错误与边界

- 「判断合并」时某本书数据缺失：跳过该书并提示，其余照常。
- 合并候选中同一本书出现在多对里：按队列顺序执行；每次执行前校验 id 仍在书库，已消失则跳过。
- 批量操作单本失败不中断整体；汇总里写明失败的書名与原因。
- 悬停浮层在鼠标快速划过时不应闪烁：延迟显示，移出立即隐藏。
- 大书库（数百本）全选判断：`findMerges` 先一次性读取全部 meta，再在内存里两两计算；IPC 异步执行，不阻塞渲染进程。

## 测试策略

遵循项目测试规范：只测关键行为，不追求覆盖率。

- `src/core/paragraphs.ts`、`src/core/position.ts`：各 1–2 条用例（正常切分、空文本；标题哈希命中与最近匹配回退）。
- `LibraryService.findMerges`：同书名不同卷 → 候选且方向正确；重叠率低于阈值 → 无候选；少于 2 本 → 空；书缺失 → 跳过不抛错。
- 渲染层无组件测试设施：以 `typecheck` + 离屏验收覆盖（选择模式 DOM、批量操作走 IPC、悬停浮层 DOM 结构），全部通过后再交用户手工抽查。

## 兼容与验收

- 旧书库（无新字段）完全兼容，无迁移。
- 验收：`npm test`、`npm run typecheck`、`npm run build` 全绿；离屏验收覆盖选择与批量；用户手工抽查清单（悬停信息、选择与批量、判断合并逐对确认）。
